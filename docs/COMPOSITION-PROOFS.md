# Composition Proofs — pre-code gate

These text proofs define materially different page compositions before implementation.

## Proof A — Home / Artwork Portal

```text
┌──────────────────────────────────────────────────────────────┐
│ LUMEN                                      EXPLORE  SEARCH ○ │
│                                                              │
│  DON'T SEARCH                                                 │
│  FOR ART.                    ┌─────────────────────────────┐   │
│  DRIFT                       │                             │   │
│  INTO IT.                    │       FOCUSED ARTWORK       │   │
│                              │                             │   │
│  001 / VISUAL CULTURE        └─────────────────────────────┘   │
│  explore by mood · color · era               ENTER ↗           │
└──────────────────────────────────────────────────────────────┘
```

First visual anchor: artwork framed/cropped by display typography.

Motion: artwork expands from the editorial frame into Explore/Drift.

Mobile transformation:
- title becomes 3–4 stacked lines;
- artwork moves below first statement;
- transition becomes crossfade/scale, no pinned scroll.

## Proof C — Relationship Atlas / spatial decision object

```text
┌──────────────────────────────────────────────────────────────┐
│ ATLAS      Selected: Untitled No.17        LIST VIEW ↗        │
│                                                              │
│                    ARTIST                                    │
│                      ●                                       │

│                     ╲                                        │
│                      ╲──● RELATED WORK                        │
│                                                              │

│  Similar dominant red field · 1950s abstraction              │
│                                                              │
│  [Open related work]                                         │
└──────────────────────────────────────────────────────────────┘
```

First visual anchor: relationship graph itself, not a hero banner.

Motion:
- connection lines reveal only when selection changes;
- linked nodes preserve position where possible;
- user can interrupt/disable motion.

Mobile transformation:
- graph becomes ordered relationship path;
- same labels and explanations; no hidden information.

## Signature test

If the logo is removed, LUMEN should still be recognizable by:
**artwork-driven contextual color + editorial/spatial composition + explicit relationship lines + object-continuity motion.**

## Cross-page monotony check

PASS hypothesis:
- Home = editorial portal.
- Detail = calm museum label/publication.
- Atlas = spatial relationship tool.

They share typography, metadata language, color behavior and motion principles without sharing one hero shell.
